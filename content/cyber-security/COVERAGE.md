# Cyber Security coverage audit

**Audit started:** 2026-09-28. A defensive topic is not complete until it teaches prevention, detection, response, recovery and realistic limitations.

- [~] CIA triad, risk, assets, threats, vulnerabilities and controls — **shallow**
- [ ] Network security, segmentation, firewalls, DNS, VPNs, secure protocols and telemetry — **missing**
- [ ] System security: hardening, patching, endpoint controls, backups and secure configuration — **missing**
- [ ] IAM: authentication, MFA, authorization, least privilege, PAM and lifecycle management — **missing**
- [ ] Cryptography: keys, hashing, PKI, TLS, encryption use cases and common failures — **missing**
- [ ] Cloud/container/application security and shared-responsibility design — **missing**
- [ ] SOC operations: logs, SIEM concepts, alert triage, threat hunting and detection engineering — **missing**
- [ ] Incident response, forensics principles, disaster recovery, business continuity and communications — **missing**
- [ ] Governance, privacy, compliance, vendor risk and secure architecture — **missing**
- [ ] Defensive capstone: detect, contain and document a simulated incident — **missing**

**Current conclusion:** Cyber Security is an early draft and needs full defensive lesson and simulation coverage.
